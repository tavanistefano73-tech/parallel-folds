# Parallel Folds

QGIS plugin for parallel fold digitization and geological cross-section analysis.

## Features

- **Parallel fold digitization** on topographic profiles
- **Topographic profile extraction** from DEM
- **Structural data projection**: strike-dip, apparent dips, and trace projection
- **Stereonet plotting** (Schmidt projection)
- **GeoPackage import/export** for data persistence
- **SVG graphic export** for publication-ready figures
- **Automatic compatibility** with QGIS 3.4+ and QGIS 4.x

## Installation

1. Download the plugin as a ZIP file from the [releases page](https://github.com/tavanistefano73-tech/parallel-folds-plugin/releases)
2. In QGIS, go to **Plugins → Manage and Install Plugins**
3. Click **Install from ZIP** and select the downloaded file
4. Activate the plugin from the **Installed** tab

Alternatively, install from the official QGIS Plugin Repository (once approved).

## Usage

Once installed, the plugin appears in **Plugins → Parallel Folds Tool**. 

For detailed usage instructions and examples, see the [documentation](https://github.com/tavanistefano73-tech/parallel-folds-plugin/wiki) (coming soon).

## Requirements

- QGIS 3.4 or higher (including QGIS 4.x)
- Python 3.6+
